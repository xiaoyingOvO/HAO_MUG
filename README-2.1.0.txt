================================================================================
HAO_MUG 微信小程序 —— 离线测试版使用说明   版本 2.1.0
================================================================================
这个包是**离线测试版**：保留了离线模拟层（miniprogram/mock/），
不需要云开发、不需要联网、不需要加入开发者，用「测试号」AppID 就能直接跑。

（另有一个「云端版」是删掉模拟层、给有云端数据库的同学接正式环境用的，
  两个包不要搞混。）

--------------------------------------------------------------------------------
一、怎么打开
--------------------------------------------------------------------------------
1. 打开「微信开发者工具」。
2. 导入项目，目录选本包的根目录。
3. AppID 选「测试号」（或用你自己的测试号），不要填正式 AppID。
4. 编译运行即可。首页会提示「模拟环境已开启」。

--------------------------------------------------------------------------------
二、离线模拟层做了什么
--------------------------------------------------------------------------------
因为测试号不支持云开发，这个包用 miniprogram/mock/cloudMock.js 把 wx.cloud 整层
接管掉了，全部走本地 storage 假数据，等价于「假装已联网、已注册」：
  - 接管 wx.cloud（init / callFunction / uploadFile / database 桩）
  - patch wx.requestPayment 为「模拟支付成功」
  - 覆盖 baseFunctions 25 个 + queueFunctions 28 个云函数类型，返回结构和真的一致
  - 数据存 storage key `haomug_mock_db_v1`，会持久化
  ⚠️ 改了 cloudMock.js 里 seed() 的机台 / 队列 / 卡片数据，必须把 DB_VERSION +1，
     否则本地缓存不刷新，会出现「机台找不到 / 机器不可用」这类假 bug。

--------------------------------------------------------------------------------
三、调试入口（真机/工具里控制台执行）
--------------------------------------------------------------------------------
   wx.resetMockData()   重置全部模拟数据
   wx.getMockState()    查看当前模拟状态
   wx.mockGrantPoints(n) 加 n 点余额
   wx.mockSetPoints(n)   把余额设为 n 点
   wx.mockSetCredit(n)   把信用分设为 n
   wx.mockSetTime('HH:MM', dayOffset)  设定虚拟时间（如 '15:00'）
   wx.mockAddHours(n)    虚拟时间 +n 小时
   wx.mockResetTime()    虚拟时间恢复真实时间

--------------------------------------------------------------------------------
四、角色开关
--------------------------------------------------------------------------------
  miniprogram/mock/cloudMock.js 顶部：
    MOCK_ENABLED  总开关（默认 true）
    MOCK_ROLE     'master' 可进管理页，其余是普通用户

--------------------------------------------------------------------------------
五、2.1.0 改了什么
--------------------------------------------------------------------------------
【入店（首页）】
 1. 点「入店」弹出设备选择弹层，选设备 → 底部按钮确认（两步确认，防误触）
 2. 舞萌合成一张卡，展开后 官机 / MML / ADX 三个独立队列；中二节奏独立队列；
    桌游/日麻一张卡
 3. 每个机台显示「游玩中 + 排队中」人数：一级卡片显示该组合计（舞萌 = 三台之和），
    展开后的官机 / MML / ADX 各自显示自己的人数
 4. 首页人数分三区域（音游区 / 桌游区 / 休息区），三者互斥、相加 = 店内总人数
 5. 首页显示**在店时长正计时**（HH:mm:ss，每秒刷新，跨天照常累计小时），
    不是入店时刻

【排卡板】
 6. 重构为「游玩区固定座位 + 等候区」：
      · 点游玩区空位（或红位）   = 切换 拼机 / 单刷（**只有舞萌·官机**支持）
      · 长按等候区的卡 300ms 拖动 = 拖到游玩区空位即上机（可指定座位），
                                  拖到等候区其他位置即调整排队顺序
      · 有人单刷时，剩余座位标红锁定
 7. 机台切换改为左侧竖排列表；进入页面会「按入店区域自动选中机台」
    （桌游区自动切到日麻）

【区域 / 计费】
 8. 新增桌游区：6 点/小时，23 点不强制离店、继续计费，跨天也能正确累计
 9. 日麻加入排队（4 人一桌）：桌游区只能排日麻，音游区只能排音游机台（跨区拉黑）；
    桌游区退队后回到休息中
10. 修：买了免单优惠卡后余额 0 也应该能入店 / 排卡 / 上机
11. 修：不满一分钟不计费（原版规则）
12. 修：音游区 0.2 点/分、桌游区 0.1 点/分；免单卡按天分别抵扣

【欠费处理】
13. 欠费不再踢人：只弹一次 toast + 页面常驻红字，队列位置保留，充值后可照常上机

【工程整理】
14. 清理无调用的死函数与死样式；清理调试用 console；项目命名统一为 2.1.0

--------------------------------------------------------------------------------
六、要恢复真实云开发怎么办
--------------------------------------------------------------------------------
删掉 miniprogram/app.js 里的两行 import + installCloudMock() 调用，
再把 project.config.json 的 appid 换成正式 AppID 即可。
（「云端版」包已经帮你做好了这些，直接要那个包就行。）

--------------------------------------------------------------------------------
七、几点提醒
--------------------------------------------------------------------------------
① 初始余额是 0 点（方便测「欠费只提醒不踢人」），要测正常流程先 wx.mockGrantPoints。
② 桌游区包夜价未定，代码里留了 BOARD_NIGHT_RATE = null + TODO。
③ 主包接近 2MB 上限，别换高清设备图，否则报 80051。
④ miniprogram/images/icons/ 里的图标已统一为 ASCII 文件名（notice-50x50.png），
   避免压缩包在 Windows 上解压出乱码。
