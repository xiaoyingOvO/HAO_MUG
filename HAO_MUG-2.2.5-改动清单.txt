本次 2.2.5：小 bug 修复（排卡板 · 等候区卡片上「我」的标识错位）

--------------------------------------------------------------------------------
一、修了什么
--------------------------------------------------------------------------------

【问题】排卡板里「我」这个标识会跑到别人的卡上：

   · 拖动某张卡时，即使被拖的人不是「我」，那张卡上也会出现「我」；
   · 有时候自己那张卡反而不显示「我」；
   · 自己在游玩区（不在等候区）时，等候区里会有人被标成「我」。

【根因】「我」是靠比较两个不同来源的列表下标判出来的，这两套下标根本对不上：

   1) 卡片组件拿到的 playerIndex，是 waitingList（只包含等候区的排队玩家）里的下标；
   2) 页面传进去的 myIndex，是 playlist（游玩区 + 等候区混排）里的下标。

   两者只是偶尔数值相等，一旦相等就误判成「我」：

   · 我在游玩区：myIndex = 0 → 等候区第 1 张卡（下标 0）被标成「我」；
   · 我在等候区第 3 位：myIndex = 3 → 等候区第 4 张卡被标成「我」，
     拖动它时克隆卡带的下标同样是 3，于是「我」就跟着别人的卡跑了；
   · 同一次改动前，拖自己那张卡反而看不到「我」。

--------------------------------------------------------------------------------
二、改了哪些文件
--------------------------------------------------------------------------------

1. miniprogram/pages/queue-info/index.js

   - 处理机台排队数据时，给每个玩家打上 isMe 标记
     （isMe = 是不是当前用户 / is current user）
   - 注释里写清了为什么不能用下标互相比较

2. miniprogram/components/card/card.wxml

   - 「我」改为按 player.isMe 显示
     （原来是 playerIndex === myIndex）

3. miniprogram/components/card/card.js

   - 删掉已经用不到的 myIndex 属性

4. miniprogram/pages/queue-info/index.wxml

   - 等候区真卡、跟手的克隆卡都不再传 my-index
   - 右侧内容模板的 data 里不再传 myIndex

--------------------------------------------------------------------------------
三、没有改动的地方（避免误解）
--------------------------------------------------------------------------------

- 底部「下机 / 退队 / 入队」按钮仍然使用页面的 myIndex
  （它表示「我在 playlist 里排第几」，这个含义本身是对的，保持原样）
- 长按拖拽、落点判定、排序云函数（delay）本次未改动
- 卡片外观没变，「我」仍然显示在昵称后面，只是改为常驻在自己那张卡上

--------------------------------------------------------------------------------
四、怎么验证
--------------------------------------------------------------------------------

【自动化】用脚本复刻了数据处理和两种判定方式，跑了 4 个真实场景：
     ① 我在等候区且前面有 2 人在玩   ② 我在游玩区（不在等候区）
     ③ 我在等候区第 3 位并拖动别人的卡  ④ 拖动自己那张卡

     修复前：4 个场景全部出错
             （场景②A 被标「我」、场景③C 被标「我」且拖 C 时显示「我」、
              场景①等候区没人显示「我」、场景④拖自己的卡没有「我」）
     修复后：4 个场景全部正确，谁是自己就标在谁身上

【手动】微信开发者工具：
     1. 入店后进排卡板，确认「我」只出现在自己那张卡上
     2. 长按拖动别人的卡 → 被拖的卡上不应出现「我」
     3. 长按拖动自己的卡 → 「我」跟着自己的卡一起走
     4. 自己上机进入游玩位后 → 等候区不应再有人显示「我」
