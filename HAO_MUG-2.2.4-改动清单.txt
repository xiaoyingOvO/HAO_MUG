--------------------------------------------------------------------------------
一、修了什么
--------------------------------------------------------------------------------

【核心问题】排卡板拖动排序：从队伍上方往下移时位置错乱

  症状：长按等候区卡片拖动调顺序，从下往上拖正常；从上往下拖会跑错位置
        ——有时被扔到队尾、有时原地不动没反应，极端情况下该玩家会从队列里
        整个消失。

  根因（三个都出在云函数 delay）：

    1) 当目标节点正好是队尾时，代码走了一条独立分支，把移动者接到队尾后面，
       而不是接到目标前面。=> 只要下移的目标是队尾那位，必然错位。

    2) 客户端拖到队尾时传 to_openid = '-1'，而云函数里 nodeMap.get('-1')
       取不到节点，直接 return，排序完全无效（前端还收到 success: true）。

    3) 摘除自己之后再插入时，找「目标的前驱」用的是摘除前的旧数据快照。
       当目标的前驱恰好就是自己时（例如拖到自己下一位之前），
       会把「自己的 next_id」写成自己，链上出现自环 —— 该玩家从此从队列消失。

--------------------------------------------------------------------------------
二、改了哪些文件
--------------------------------------------------------------------------------

1. cloudfunctions/queueFunctions/delay/index.js   （重写队列插入逻辑）

   - 统一语义：把移动者插到目标「前面」；to_openid === '-1' 表示排到队尾
   - 删除「目标为队尾 → 插到队尾之后」的错误分支
   - 补上 '-1'（拖到队尾）的处理，原来这条路径是失效的
   - 找目标前驱改为沿「摘除自己之后」的活链表遍历，杜绝自环
   - 抽出 updateNextId()，统一「改内存节点 + 写数据库」动作
   - 排序失败改为返回 { success:false, errMsg }（前端会 toast 提示），
     不再 console.error 后静默 return
   - 失败路径也释放机台锁（原来失败时只打日志就返回，锁会一直被占住，
     该机台后续所有人排不了队）
   - final_place 由模块级全局变量改为函数返回值（多人同时排序时，
     全局变量会被互相覆盖，写进日志的「第 N 位」会串号）

2. miniprogram/mock/cloudMock.js   （离线模拟层同步修改）

   - Delay() 改为「先确认目标还在队列中，再摘除自己」，
     否则目标已不在时会把用户摘掉却插不回去（离线环境同样会丢人）
   - 删掉 Math.max(0, idx) —— 这种写法会把异常情况伪装成正常，让问题更难查
   - 删掉一行调试用 console.log

3. project.config.json / project.private.config.json

   - projectname：HAO_MUG-2.2.3 → HAO_MUG-2.2.4

四、怎么验证
--------------------------------------------------------------------------------

【自动化】用内存数据库替身把 delay 云函数跑了 10 个场景：
     队首下移一位 / 队首下移到队尾 / 队中下移 / 队尾上移到队首 /
     队尾上移一位 / 原地不动 / 拖到自己下一位之前 / 两人队尾移队首 /
     三人移队尾 / 三人队尾移中间

     修复前：5 通过 / 5 失败（失败全是下移类，其中 1 例玩家从队列消失）
     修复后：10 通过 / 0 失败

【手动】微信开发者工具（离线模拟版直接可测）：
     1. 首页入店 → 排卡板，选一个已排 3 人以上的机台
     2. 长按等候区第 1 张卡，往下拖到第 3、第 4 张之间松手 → 应停在该位置
     3. 长按最下面一张卡，往上拖到第 1 位之前松手 → 应排到队首
     4. 长按某张卡，往下拖到队尾下方（超出最后一张）松手 → 应排到队尾
     5. 长按某张卡，拖到它自己下一位之前松手 → 顺序不变，不能有人消失

   ⚠️ 云端环境需要重新上传部署 delay 云函数后再测：
     右键 cloudfunctions/queueFunctions → 上传并部署（云端安装依赖）
     （如有独立部署入口，单独部署 delay 这一个函数也可以）
